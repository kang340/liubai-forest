# 留白 · 林间工作台

**[🌿 打开在线工作台](https://kang340.github.io/liubai-forest/)** · 无需安装，点击即可使用。

把心安放，让事情慢慢生长。

一个可以离线运行的自然主题工作台。在溪流、树林和鸟鸣之间，管理待办、记录灵感、给自己留一段专注时间。

## 这次的变化

- **三种自然场景**：晨光溪谷、林间细雨、萤火之夜，包含溪水流动、树梢轻摇、飞鸟、雨丝与萤火。
- **轻音乐与自然声**：三段不同的循环旋律，轻音乐、溪流／雨声、鸟鸣分别调节；点击播放后才发声。
- **沉浸专注**：保留风景、声音控制和计时器。点击“退出沉浸”或按 Escape 返回。
- **专注小树林**：每完成一次计时，累计增加一棵树；与原有专注次数同步。
- **保留工作台功能**：待办添加、编辑、删除、筛选，15／25／45 分钟专注计时，自动保存便签，明暗主题，JSON 备份导入导出。
- **动效开关**：可关闭动画；首次打开时尊重系统的减少动态效果设置。页面隐藏时暂停景物动画。
- **移动端备份入口**：小屏也能导出与恢复数据。

## 本地打开

解压后双击 `index.html`，用浏览器打开即可。没有 npm 安装、构建步骤、远程图片、远程字体或音乐外链。

音乐使用 Web Audio 合成，属于柔和的琴音／拨弦氛围旋律；自然声也是程序合成，并非真实环境录音。三个音量滑块拉到 0 可以分别静音。切换场景时，已奏出的音符会自然衰减。

## 数据与迁移

- 待办、便签与计时状态保存在当前浏览器的 `liubai-workspace-v1`，保持原版数据结构与备份格式兼容。
- 场景、声音音量与动效偏好保存在 `liubai-forest-v2`。偏好会在同一浏览器保留；工作台 JSON 备份仅包含待办、便签、专注累计和工作台设置。
- 本地文件与线上网址、不同浏览器之间的数据不会自动同步。迁移时先在旧页面导出，再在新页面导入。
- 清除浏览器网站数据可能清除工作记录，请按需导出备份。
- 所有访客各自使用本机数据。页面没有账号服务、远程数据库、统计追踪或上传用户工作记录的接口。

## GitHub Pages 发布

把本文件夹中的 `index.html`、`.nojekyll` 和 `README.md` 放在一个公开仓库的根目录。

在仓库的 **Settings → Pages** 中设置：

1. Source：**Deploy from a branch**。
2. Branch：**main**，目录：**/(root)**。
3. 保存，等待 GitHub Pages 发布完成，使用设置页显示的正式网址。

后续提交新的 `index.html` 即可触发更新。不要只上传 ZIP 文件；Pages 需要解压后的网页文件。

参考：[GitHub 官方发布源配置说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。
